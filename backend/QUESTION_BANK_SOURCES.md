# Nebula starter quiz question references

The starter DSA and Python diagnostic questions in `app.py` are original questions written for Nebula. GeeksforGeeks articles were used as concept references; question wording and answer options are not copied.

- DSA operation complexity: https://www.geeksforgeeks.org/dsa/time-complexities-of-different-data-structures/
- Python collections: https://www.geeksforgeeks.org/python/differences-and-applications-of-list-tuple-set-and-dictionary-in-python/
- Searching and linked-list access: https://www.geeksforgeeks.org/dsa/commonly-asked-data-structure-interview-questions-on-searching/

The questions cover stacks, queues, binary search, linked-list traversal, breadth-first search, hash-table lookup, array indexing, and Python collection behavior. Each question is tagged with a curriculum topic so results can inform topic-level mastery and study-plan priorities.

## Other demo-course diagnostics

`starter_quizzes.py` contains original eight-question baseline checks for the other 23 courses in the CSV catalog. The questions are concept-level starters authored for Nebula; they are not copied from GeeksforGeeks or another question bank. They demonstrate the quiz and personalization flow, but they are not a comprehensive or teacher-reviewed question bank. Review and expand them before using them for formal assessment.
